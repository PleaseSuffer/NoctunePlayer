# Пример Themes API v2

Эта небольшая тема показывает композицию слоёв, альфа-маску зданий, общий спектр для нескольких эффектов, отражение на воде и настройки slider/toggle/select. PNG-ресурсы генерируются локальным скриптом; внешние сервисы не нужны.

## Запуск своей темы

Из корня проекта:

```powershell
Copy-Item -Recurse themes/examples/api-v2 themes/user/my-theme
```

В новой папке измените `manifest.id` на `my-theme`, `name`, описание и автора. Для новой темы обязательно используйте собственный ID: он связывает обновления и сохранённые настройки. Оставьте `apiVersion: 2`. `width`/`height` — логические координаты сцены, а `assets` — относительные пути к PNG. `preview` указывает ID одного из PNG-слоёв.

Плеер обнаружит папку при запуске или обновлении галереи. Код сцены находится в `scene.js`: `NoctuneScene.define` регистрирует `render(api, frame)`, который вызывает сам плеер. Рисуйте через `api.ctx` и методы SDK. Для частиц и поз используйте `api.time`, для собственных буферов — `api.createSurface` и `api.releaseSurface`. При использовании масок берите `api.ctx` внутри callback, потому что SDK временно заменяет контекст.

## Настройки и музыка

`parameterSchema` объявляет типы и ограничения настроек. Они автоматически появятся в плеере; значения доступны через `frame.parameters`. `api.bandsSource` возвращает сглаженный спектр 0…1. Один массив можно передать в `bars`, `line` и отражение: эти эффекты используют одинаковую выборку частот. Значения `attack` и `release` задают скорость временного сглаживания; `smoothing` — сглаживание соседних полос.

`api.clipMask` использует прозрачность PNG, а не его яркость: у чёрно-белого непрозрачного PNG сначала нужно преобразовать яркость в альфа-канал. Для столбиков позади объекта рисуйте фон, затем спектр, затем PNG переднего плана с прозрачностью вокруг объекта.

## Упаковка и обновление

```powershell
node scripts/pack-scene-theme.cjs themes/user/my-theme themes/user/my-theme.noctheme
```

Импортируйте пакет через кнопку + или откройте файл `.noctheme`. Для обновления увеличьте `manifest.version`, сохранив ID, и упакуйте снова. Окно установки предложит «Обновить»; активная сцена перезагрузится автоматически с сохранением настроек. Неудачный запуск новой сцены оставляет старую активной.

Локальные кастомные темы исключены из Git. Справочный пример и его готовый пакет `themes/packages/api-v2-demo.noctheme` публикуются вместе с SDK.

Полный контракт, ограничения ресурсов, события и профили качества: [SCENE-API-V2.md](../../../docs/SCENE-API-V2.md). Типы: [scene-sdk.d.ts](../../../src/renderer/effects/scene-sdk.d.ts).
