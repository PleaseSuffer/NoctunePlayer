# Пользовательские темы

Создавайте исходники тем здесь: `themes/user/my-theme/manifest.json`, `scene.js`, `assets/*.png`.
Можно также положить сюда готовый `my-theme.noctheme`. Имена директорий и пакетов: строчные латинские буквы, цифры и дефисы. Плеер обнаруживает их при запуске и обновлении галереи.

В разработке плитка + в разделе «Темы» сохраняет импортированные пакеты в эту же папку. Крестик доступен для всех добавленных тем. Импортированные копии удаляются; папки исходников и поставляемые пакеты скрываются из галереи без удаления исходных файлов. Состояние хранится в `.hidden-themes.json` каталога импорта и сохраняется после перезапуска. Повторная установка возвращает тему. Одинаковые `manifest.id` объединяются в одну карточку; выбирается новейшая версия, при равенстве — импортированный пакет.

Кастомные темы, промпты, исходные изображения и предпросмотры остаются локально и исключены из Git. Справочный пример API v2 находится в `themes/examples/api-v2`. Сборка включает локальные файлы `themes/user`, поэтому проверьте содержимое папки перед созданием распространяемой сборки.

В установленном приложении новые импорты сохраняются в `app.getPath('userData')/themes/user`, поскольку ресурсы внутри app.asar доступны только для чтения. Обе коллекции объединяются в галерее. Старые импорты из каталога `scene-themes` автоматически копируются в новое место с сохранением ID.

Описание API: [SCENE-THEMES.md](../../docs/SCENE-THEMES.md), [SCENE-API-V2.md](../../docs/SCENE-API-V2.md).
