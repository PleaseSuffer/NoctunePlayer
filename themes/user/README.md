# Пользовательские темы

Создавайте исходники тем здесь: `themes/user/my-theme/manifest.json`, `scene.js`, `assets/*.png`.
Можно также положить сюда готовый `my-theme.noctheme`. Имена директорий и пакетов: строчные латинские буквы, цифры и дефисы. Плеер обнаруживает их при запуске и обновлении галереи.

В разработке плитка + в разделе «Темы» сохраняет импортированные пакеты в эту же папку. Все её файлы входят в сборку. Исходники и поставляемые вместе с приложением пакеты нельзя удалить кнопкой галереи: удаление доступно для импортированных копий.

В установленном приложении новые импорты сохраняются в `app.getPath('userData')/themes/user`, поскольку ресурсы внутри app.asar доступны только для чтения. Обе коллекции объединяются в галерее. Старые импорты из каталога `scene-themes` автоматически копируются в новое место с сохранением ID.

Описание API: [docs/SCENE-THEMES.md](../../docs/SCENE-THEMES.md).
