# Пользовательские темы магазина

Исходники опубликованных тем сообщества находятся в отдельных каталогах с ID
из manifest.json. Порядок карточек задаётся в order.json.

1. **Rhodes Island / PRTS Black** — тёмная тема Arknights.
2. **Rhodes Island / Medical White** — светлая тема Arknights.
3. **Endfield / Night Shift** — тёмная тема Arknights: Endfield.
4. **Endfield / Day Shift** — светлая тема Arknights: Endfield.

Это неофициальные фанатские темы. Источники логотипов и сведения о правообладателях
указаны в SOURCES.txt внутри соответствующих каталогов.

Пакеты .noctheme находятся в addons/distribution, карточки — в подписанном
addons/catalog/marketplace.json. Полные темы не входят в установщик плеера.
Локальные импорты и эксперименты по-прежнему хранятся в themes/user.

Сборка и подпись описаны в [инструкции публикации](../../docs/extensions-publishing.md).
