# Perlica / Afterimage

Аудиореактивная community-тема для Noctune с Перликой из Arknights: Endfield.
Автор темы — **Noctune Community**, версия **1.7.1**, API тем v2, композиция FullHD.
Светлый интерьер — авторская стилизация станции, а не точная реконструкция Дицзяна.

Установите тему из **NocStore → Темы → Пользовательские** либо скачайте
[пакет 1.7.1](../../../addons/distribution/perlica-afterimage/1.7.1/perlica-afterimage-1.7.1.noctheme)
и откройте его в Noctune. Дополнительный экспорт находится в
[themes/packages](../../packages/perlica-afterimage.noctheme).

## Поведение

Басовые акценты раскрывают фрагменты второго состояния Перлики: пустой взгляд,
царапины и следы крови. Полосы появляются с разными задержками, перемещаются,
сужаются и исчезают независимо. Повторные удары добавляют новые полосы, сохраняя
таймеры старых; пул ограничен 48 элементами. Плотный бас поддерживает более
длительные фрагменты памяти между ударами.

Голубая телеметрия меняется на сообщения об ошибках. Отдельные строки,
повреждённая разметка, блоки помех и карантин восстанавливаются по собственным
таймерам. Короткая волна замены символов на сильных ударах идёт справа налево;
между волнами остаётся время для чтения. Световые импульсы перемещаются по
направляющим, а независимые линии обходят рамку. По умолчанию одновременно
может работать восемь линий, настраиваемый предел — от двух до шестнадцати.

Параллакс плавно следует за курсором. Портрет заполняет фиксированную рамку
с запасом для движения. Левая панель, включая спектр, надписи и разметку,
движется единым слоем. После ухода курсора сцена возвращается в центр.
Пауза, выключенная аудиореакция и режим уменьшения движения останавливают
басовые эффекты; уменьшение движения также отключает параллакс.

## Настройки

Настраиваются чувствительность, минимальный бас в dB, отбор относительно
недавнего пика, сила глитчей, длительность следа, память при плотном басе,
порча интерфейса, анимации текста, световые импульсы, глубина параллакса,
лимит линий, спектр и звёзды.

Диапазон анализа — 35–180 Гц. Байты FFT переводятся из шкалы анализатора
−90…−10 dB в линейную мощность перед расчётом RMS. Минимальный порог
по умолчанию −46 dB, относительный — 35% недавнего пика; гистерезис около
2 dB предотвращает дребезг. Анализ причинный: будущий звук не сканируется.

## Исходники и сборка

- `manifest.json` — метаданные и пользовательские настройки.
- `scene.js` — Canvas-сцена без DOM и сетевых запросов, совместимая с Worker.
- `assets/calm.png`, `assets/grief.png` — два состояния портрета.
- `assets/preview.png` — статичное превью.

Из корня репозитория:

```sh
node scripts/pack-scene-theme.cjs themes/community/perlica-afterimage themes/packages/perlica-afterimage.noctheme
npm test
```

Проверены повторные удары и тихие низы, независимые таймеры, лимиты пулов,
восстановление после паузы, уменьшение движения, узкие и широкие окна,
крайние положения курсора при максимальном параллаксе и 30/60/144 FPS.
Тема также проверялась на музыкальных фрагментах с настройками FFT плеера.
Музыка в пакет и превью магазина не включена.

Иллюстрации основаны на предоставленном референсе Перлики; состояния подготовлены
с помощью AI-редактирования. Автор исходного арта не установлен. Подпись каталога
подтверждает целостность распространения и не делает community-тему официальной.
