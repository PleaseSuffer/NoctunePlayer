# Endministrator / Fracture

Тёмная неофициальная тема **Noctune Community** для Noctune, SDK тем 2.
Графитовая станция, фиолетовая телеметрия и два состояния Эндмина.

## Реакция на музыку

Бас 35–180 Гц раскрывает угловатые фрагменты треснувшей маски. Фрагменты,
осколки заражения, разряды, сканирующие импульсы и контуры рамки имеют
независимые сроки жизни и ограниченные пулы. Пауза и reduced motion
возвращают спокойное состояние.

Квадратная волна со скруглениями медленно расходится из центра портрета.
Символы искажаются только при пересечении её фронта. Портрет перекрывает
видимую волну и её свечение. Параллакс инвертирован, глубина портрета
немного больше глубины интерфейса.

## Интерфейс и настройки

Панель показывает давление баса в dB, логарифмический спектр 35 Гц–12 кГц
и состояние подсистем. Название трека и исполнитель берутся из необязательных
полей frame.playback.title/artist: требуется сборка плеера с их поддержкой.
Старые сборки показывают AWAITING TRACK DATA.

Настраиваются чувствительность, порог баса, проявление трещин, длительность
следа, параллакс, смещение фрагментов, волны текста, спектр, частицы,
четыре вида эффектов рамки и их общая яркость.

## Обновление 1.12.0

Текстовая панель получила плавный дрейф, прокрутку строк при смене состояния,
поочерёдное декодирование подписей и дыхание подсветки. Название трека и
исполнитель анимируются при смене; показания dB обновляются без задержки.
Параметры animatedText, textFloat, textTransitions, textDecode и textBreathing
позволяют настроить или отключить эффекты. При reduced motion они остановлены.
