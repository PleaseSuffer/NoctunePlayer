# Возможности

## Музыкальный плеер

- Воспроизведение локальных аудиофайлов
- Открытие аудиофайлов из файлового менеджера и выбор Noctune плеером по умолчанию в Windows и Linux
- Подменю Noctune в Проводнике Windows: воспроизведение, новый плейлист, добавление в плейлист и очередь
- Drag & Drop аудиофайлов в открытый музыкальный плейлист без прерывания воспроизведения
- Поддержка MP3, WAV, OGG, M4A и FLAC
- Поддержка плейлистов
- Случайный порядок и повтор
- Изменение скорости воспроизведения
- Мини-плеер
- Полоса перемотки
- Автоматическое сохранение состояния
- Удобное управление треками
- Настраиваемое затухание в конце трека и нарастание в начале следующего: длительность и интенсивность
- ReplayGain по метаданным файла, баланс L/R и выбор режима каналов
- Настраиваемые горячие клавиши
- Discord Rich Presence — отображение играющего трека и статуса воспроизведения в вашем профиле Discord
- Импорт и экспорт плейлистов `.m3u`

## Интернет-радио

Noctune поддерживает полноценную работу с интернет-радиостанциями:

- Добавление потоков вручную
- Поиск станций через API
- Фильтрация по:
  - странам
  - тегам
  - названию
- Расширенная проверка доступности радиостанций перед воспроизведением
- Отображение актуального статуса потоков
- Редактирование станций
- Контекстное меню управления
- Исполнитель и название текущей композиции, если станция передаёт метаданные
- Название станции вместо полосы перемотки в окне текста песни
- Автоматический поиск обложки текущей композиции при включённых Last.fm и поиске обложек

## Last.fm

Last.fm используется для истории прослушиваний и загрузки обложек. Для скробблинга нужно подключить аккаунт; получение обложек не требует входа в аккаунт.

- Авторизация и подключение аккаунта
- Scrobbling воспроизводимых треков
- Передача информации о текущем треке
- Управление интеграцией через настройки плеера
- Загрузка обложек, если изображение не встроено в аудиофайл
- Дисковый кэш с лимитом 10–300 МБ, отображением занятого размера и автоматическим удалением старых обложек
- Хранение в кэше приложения, в отдельной подпапке каждой папки с музыкой или в выбранной пользователем папке
- Очистка кэша и открытие текущей папки обложек из настроек

Сохранённые обложки доступны без повторного скачивания, в том числе без интернета. Встроенные обложки имеют приоритет. В режиме хранения рядом с музыкой размер и очистка относятся к папке текущего трека; лимит действует отдельно для каждой папки.

Обложки радио не используют постоянный кэш: изображение хранится в памяти на время текущей композиции. При смене трека или станции устаревшие запросы отменяются.

## Тексты песен · LRCLIB

Получение текстов песен без регистрации и ввода API-ключа:

- Обычные и синхронизированные тексты, если они доступны в LRCLIB
- Подсветка текущей строки, автопрокрутка и перемотка нажатием на строку
- Обычное окно и развёрнутый режим с обложкой и управлением воспроизведением
- Сохранение выбранного обычного или развёрнутого режима между открытиями текста
- Плавное центрирование обложки, когда текст отсутствует
- Настройки цвета текста: адаптивный, акцентный, собственный, светлый или тёмный
- Настройки размера и тени текста, яркости неактивных строк, затемнения и размытия фона
- Кэширование результатов в памяти и до пяти попыток каждого запроса при временной сетевой ошибке
- Отмена незавершённого поиска при смене трека или закрытии окна текста

Настройки оформления текста находятся во вкладке «Внешний вид» при включённой интеграции LRCLIB и включаются в экспорт темы. Поиск запускается при открытии текста и учитывает метаданные и длительность песни.

## Производительность

В версии 1.3.0 снижено потребление памяти при переключении длинных треков и работе с обложками:

- Waveform строится последовательно; устаревшие задания пропускаются. После декодирования сохраняются 200 байт пиков вместо полного аудиобуфера.
- Готовые waveform сохраняются на диске и переиспользуются после перезапуска. Изменение файла приводит к повторному построению.
- Для списка треков используются миниатюры до 96 px; встроенная обложка активного трека загружается отдельно с размером до 1024 px.
- В «Основные → Производительность» доступны аппаратное ускорение и ограничение эффектов до 30/60 FPS либо режим без ограничения.
- Аппаратное ускорение включено по умолчанию; его изменение сохраняется и применяется после перезапуска через кнопку рядом с настройкой.
- При сворачивании в трей сохраняется прежняя приостановка отрисовки эффектов. Фоновое видео не выгружается, поэтому не требует повторной загрузки при возвращении.

Ограничение FPS относится к визуализатору, звёздам, конфетти и эффектам фона. Оно не ограничивает частоту воспроизведения фонового видео. Фактическое потребление памяти зависит от библиотеки, эффектов, фонового видео и платформы.

# Установка

Готовые опубликованные сборки доступны в [GitHub Releases](https://github.com/PleaseSuffer/NoctunePlayer/releases).
Для запуска из исходников нужны Node.js и npm.

## Клонирование репозитория

```bash
git clone https://github.com/PleaseSuffer/NoctunePlayer.git
cd NoctunePlayer
```

## Установка зависимостей

```bash
npm ci
```

## Сборка приложения

```bash
npm run dist
```

Команда собирает приложение для текущей платформы. В конфигурации предусмотрены NSIS для Windows и AppImage, pacman, tar.gz для Linux. Результат сборки находится в `dist/`.

При первой установке в Windows доступен мастер с выбором папки и режима установки. Если в выбранном режиме (для пользователя или всех пользователей) уже зарегистрирована установка и её `Noctune.exe` существует, повторный запуск установщика обновляет приложение в прежней папке без мастера и запускает плеер после завершения. Устаревшая запись в реестре без самого приложения не включает этот режим. Автоапдейтер использует тихую установку с последующим запуском; при установке для всех пользователей Windows может запросить повышение прав.

## Открытие файлов и плеер по умолчанию

Поддерживаются `.mp3`, `.wav`, `.ogg`, `.m4a` и `.flac`. Открытие одного или нескольких файлов запускает Noctune либо передаёт их уже работающему плееру, в том числе свёрнутому в трей. Файлы добавляются в отдельный плейлист «Открытые файлы» без дубликатов; первый переданный трек начинает воспроизводиться. Личные плейлисты сохраняются.

**Windows:** установщик регистрирует Noctune в меню «Открыть с помощью», добавляет подменю «Noctune» для аудиофайлов и делает плеер доступным в системных приложениях по умолчанию. Подменю содержит «Воспроизвести», «Открыть в новом плейлисте», «Добавить в плейлист» и «Добавить в очередь». Добавление в текущий музыкальный плейлист или очередь сохраняет воспроизведение текущего трека; очередь проигрывается в порядке добавления после текущего трека или при нажатии «Следующий». Если трек ещё не выбран, очередь начинает воспроизводиться сразу. При открытом радиоплейлисте действие «Добавить в плейлист» отклоняется. В Windows 11 подменю может находиться в меню «Показать дополнительные параметры». В плеере откройте «Настройки → Основные → Системная интеграция → Выбрать по умолчанию», затем выберите Noctune для нужных расширений. Установка не меняет существующий плеер по умолчанию; удаление приложения убирает его регистрацию.

**Linux:** установленный пакет предоставляет запись `.desktop` с аудиоформатами для меню «Открыть с помощью». Для AppImage и распакованной сборки откройте «Настройки → Основные → Системная интеграция → Добавить в „Открыть с помощью“». Приложение создаст запись и скопирует иконку в пользовательский каталог `$XDG_DATA_HOME` (по умолчанию `~/.local/share`). Храните AppImage или распакованную сборку в постоянной папке; после перемещения нажмите эту кнопку снова. Для назначения плеера по умолчанию нажмите «Назначить по умолчанию»; требуется `xdg-mime` из пакета `xdg-utils`. Если окружение рабочего стола ограничивает изменение ассоциаций, выберите Noctune через свойства файла. При ручном удалении переносимой сборки можно удалить `applications/com.noctune.player.desktop` и `icons/hicolor/512x512/apps/com.noctune.player.png` из пользовательского каталога данных.

Регистрация в системе доступна в готовых сборках. Обработку файлов из исходников можно проверить командой `npm start -- "/путь/к/песне.mp3"`.

Для Drag & Drop откройте музыкальный плейлист и перетащите аудиофайлы в левую панель плеера. Треки добавляются без дубликатов и сохраняются, включая файлы вне основной папки плейлиста. Радиоплейлисты не принимают аудиофайлы; неподдерживаемые форматы, папки и недоступные файлы пропускаются.

## Проверки

```bash
npm test
```

Проверки охватывают воспроизведение, получение текстов и обложек, кэширование, компактный waveform, отмену устаревших запросов, метаданные радио, настройки производительности, интерфейс текста песни, синтаксис renderer-скриптов и пути подключения модулей и ресурсов.

Отдельные проверки с настоящим Electron для памяти и миниатюр запускаются вручную и не входят в `npm test`. Команды и ограничения приведены в [документации структуры проекта](docs/PROJECT_STRUCTURE.md#проверки).

Сценарии первой установки и обновления Windows можно проверить командой `node tests/native-installer-policy-probe.cjs`. Проверка компилирует и выполняет NSIS-инициализацию на временных файлах с подставленными входными данными реестра и командной строки; приложение не устанавливается, реестр Windows не изменяется. Требуется доступ к компонентам NSIS в кэше electron-builder либо возможность их загрузить.

# Безопасность

Noctune использует изолированную архитектуру Electron:

- `contextIsolation` включён для изоляции renderer-процесса
- IPC-взаимодействие выполняется через безопасный `preload` bridge
- Node.js API не предоставляются напрямую веб-интерфейсу
- Настройки и состояние приложения хранятся через `electron-store`
- Доступ renderer к системным возможностям ограничен API, опубликованным preload-слоем

## Обновления

Для обновлений используется `electron-updater`.

- Проверка обновлений выполняется через встроенный updater workflow
- Доступны автоматическая загрузка и установка обновлений
- Поведение обновлений можно настраивать в зависимости от предпочтений пользователя
- Пользователь получает уведомления о доступности и состоянии обновления
