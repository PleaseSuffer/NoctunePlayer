# ✨ Возможности


## 🎵 Музыкальный плеер

- Воспроизведение локальных аудиофайлов
- Поддержка плейлистов
- Случайный порядок и повтор
- Изменение скорости воспроизведения
- Мини-плеер
- Полоса перемотки
- Автоматическое сохранение состояния
- Удобное управление треками

## 📻 Интернет-радио

Noctune поддерживает полноценную работу с интернет-радиостанциями:

- Добавление потоков вручную
- Поиск станций через API
- Фильтрация по:
  - странам
  - тегам
  - названию
- Проверка статуса радиостанций
- Редактирование станций
- Контекстное меню управления

## 📊 Эквалайзер

Встроенный 12-полосный эквалайзер:

- 12 полос настройки
- Preamp
- Включение и отключение
- Пользовательские пресеты
- Сохранение настроек
- Быстрое переключение профилей


## 🎨 Интерфейс

### Внешний вид
- Полупрозрачный интерфейс
- Эффекты размытия
- Плавные анимации
- Всплывающие уведомления
- Контекстные меню
- Удобная панель настроек

### Настройка
- Светлая и тёмная тема
- Цветовые акценты
- Настройка визуализатора
- Отображение обложек
- Настройки поведения плеера

# 🚀 Установка

## Клонирование репозитория

```bash
git clone https://github.com/PleaseSuffer/NoctunePlayer.git
cd noctune-player
```

## Установка зависимостей

```bash
npm install
```

## Сборка приложения

```bash
npm run dist
```

# 🧠 Особенности реализации

## Звуковой движок

Noctune использует:

- Web Audio API
- Кастомный аудио-движок на базе initAudioEngine для оптимизированной работы с потоками
- GainNode
- Audio Filters
- Обработку звука в реальном времени

## Возможности Electron

- Системные диалоги
- Управление окнами
- Локальное хранение данных
- Работа с файловой системой
- Desktop-рендеринг
- Полная интеграция с System Media Transport Controls (SMTC) для управления с клавиатуры и экрана блокировки
