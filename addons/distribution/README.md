# Официальные пакеты расширений

Здесь хранятся подписанные пакеты для установки и обновления через магазин Noctune.
Структура: `<id>/<version>/<id>-<version>.noctaddon`.

Исходники находятся в [official](../official/), подписанный список — в
[catalog/official.json](../catalog/official.json). Пакеты не входят в установщик
плеера и загружаются отдельно после подтверждения пользователя.

Генератор `scripts/publish-official-addons.cjs` обнаруживает расширения по их
manifest, собирает пакеты и обновляет каталог. Уже опубликованные файлы сохраняют
неизменными. Для обновления увеличивают версию и ревизию расширения; старые пакеты
остаются доступными для сохранённых копий каталога.

[Порядок публикации](../../docs/extensions-publishing.md#официальные-расширения-из-основного-репозитория).
