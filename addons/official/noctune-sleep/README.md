# Noctune Sleep

Официальное расширение Noctune · версия 1.0.0 · SDK 1 · Noctune 1.4.0.

Таймер ставит музыку или радио на паузу через заданное время. Перед завершением
звук плавно затихает, а выбранная вами громкость плеера сохраняется.

## Установка и управление

Установите подписанный `.noctaddon` через «Настройки → Расширения» и включите
расширение. Нажмите «Запустить таймер». Команды также можно назначить на сочетания
в разделе «Горячие клавиши».

- **До паузы, минут** — 5–180 минут; новая длительность применяется при следующем старте.
- **Плавное затихание** и **Затихание, секунд** — мягкое снижение звука за последние 5–60 секунд.
- **Запускать при включении** — новый таймер при включении расширения и запуске плеера; по умолчанию выключено.
- **Отменить таймер** — снять таймер и вернуть звук.
- **Добавить 5 минут** — продлить текущий таймер либо запустить новый, если он не работает.
- **Сколько осталось** — показать оставшееся время уведомлением.

Таймер учитывает реальное время: после сна компьютера истёкший таймер сработает
при возобновлении работы приложения. При закрытии плеера или отключении Sleep
таймер отменяется; он не выключает компьютер. Смена трека не сбрасывает отсчёт.
Затихание выполняется собственным слоем Web Audio, без изменения ползунка громкости.
Отключение или ошибка расширения снимают этот слой. Если затихание недоступно,
пауза остаётся запланированной.

## Разрешения

- `settings.read`, `settings.events` — настройки длительности и затихания.
- `playback.pause` — поставить текущее воспроизведение на паузу по таймеру.
- `audio.gain` — временное затихание только собственного слоя.
- `notifications.show` — запуск, отмена, оставшееся время и завершение.
- `hotkeys.register` — команды для пользовательских горячих клавиш.

Доступа к файлам, сети, токенам и истории прослушивания нет. Настройки сохраняет
плеер; активный отсчёт существует только в памяти.

## Обновления и подпись

Обновления устанавливаются новым подписанным пакетом. Официальность проверяется
ключом Noctune, встроенным в плеер; публичная идентичность опубликована в
`addons/official/publisher.json`. Канал автоматических обновлений для этого пакета
не объявлен. Лицензия: MIT, см. `license.txt`.
