# Официальные расширения Noctune

| Расширение | Назначение |
| --- | --- |
| [Noctune Chroma](noctune-chroma/README.md) | Плавное переливание цвета акцента |
| [Noctune Sleep](noctune-sleep/README.md) | Таймер сна с плавным затиханием |
| [Noctune Shades](noctune-shades/README.md) | Шесть спокойных цветовых схем |
| [Noctune Dusk](noctune-dusk/README.md) | Схемы и обои по расписанию |

Расширения используют SDK 1 и требуют Noctune 1.4.0 или новее.
Для установки пакета `.noctaddon` откройте «Настройки → Расширения».
Возможности, настройки и разрешения описаны на странице каждого расширения.

Официальность проверяется по цифровой подписи пакета. Публичный ключ Noctune
и его SHA-256 отпечаток опубликованы в [publisher.json](publisher.json).

[Документация SDK расширений](../../docs/extensions-api-v1.md).
