# Noctune Chroma

Официальное расширение Noctune · версия 1.0.0 · SDK 1 · Noctune 1.4.0.

Плавно меняет цвет акцента поверх текущей темы. Работает локально, без доступа
к сети, трекам, файлам или аудиоданным. Градиенты визуализатора и параметры темы
остаются под управлением плеера. Отключение эффекта или самого расширения сразу
возвращает актуальный цвет темы, в том числе после смены темы во время анимации.

## Установка

В актуальной сборке Noctune откройте **Настройки → Расширения → Добавить из файла**,
выберите `noctune-chroma-1.0.0.noctaddon`, проверьте отметку «Официальное расширение»
и подтвердите установку. Затем включите расширение переключателем в его карточке.
Настройки доступны в раскрывающемся разделе «Настройки расширения».

## Настройки

- **Палитра:** полный RGB-цикл, Северное сияние, Закат, Океан, Неон или свои цвета.
- **Своя палитра:** 2–12 цветов `#RRGGBB` или `#RGB`, разделённых запятыми,
  пробелами или `;`. Например: `#ff6b9d, #a78bfa, #38bdf8`.
  Этот набор используется в режиме «Свои цвета». Некорректный ввод сохраняет
  последнюю корректную палитру до перезапуска расширения; затем используется
  исходный набор, если ввод всё ещё некорректен. Ошибка сопровождается уведомлением.
- **Длительность цикла:** 6–300 секунд; по умолчанию 45. В круговом режиме
  включает возвращение от последнего цвета к первому. В режиме «Туда и обратно»
  включает прямой и обратный проход.
- **Направление:** по кругу, в обратную сторону или туда и обратно.
- **Переходы:** равномерная RGB-интерполяция либо мягкое замедление около каждого
  цвета. Полный радужный цикл равномерно проходит цветовой круг HSV.
- **Насыщенность и яркость:** масштабируют исходные цвета, не меняя сохранённую
  палитру. Для точных своих цветов установите оба значения на 100%.
- **Начальная точка:** сдвиг цикла в градусах, 0–359.
- **Частота:** 20 кадров/с или экономный режим 10 кадров/с.
- **Переливание акцента:** временная пауза с возвратом цвета темы. Повторное
  включение продолжает с прежней позиции; отключение всего расширения сбрасывает цикл.

Кнопка **«Начать цикл заново»** возвращает к заданной начальной точке.
Кнопка **«Проверить свою палитру»** проверяет формат и количество цветов.
Изменение скорости не сбрасывает позицию. Анимация идёт независимо от воспроизведения.
Собственные окна, перехват интерфейса и фоновые сетевые запросы не используются.

## Разрешения

| Право | Для чего |
| --- | --- |
| `settings.read` | Прочитать настройки Chroma |
| `settings.events` | Применять изменения без перезапуска |
| `themes.accent` | Временный слой акцента, автоматически снимаемый при остановке |
| `notifications.show` | Результат проверки палитры и сообщение об ошибке |

При нескольких расширениях, меняющих акцент, приоритет получает последний
созданный слой. Изменения цвета внутри уже созданного слоя приоритет не меняют.

## Обновления и подпись

Пакет подписан Ed25519 ключом Noctune. Публичный ключ и его SHA-256 отпечаток
опубликованы в `addons/official/publisher.json` исходного репозитория. Плеер
сверяет подпись с собственным доверенным ключом и отдельно показывает отпечаток
издателя при установке. Для обновления установите новый подписанный пакет:
его ключ должен совпасть, а ревизия должна увеличиться. Сетевой канал обновлений
пока не опубликован. Лицензия: MIT, см. `license.txt`.
