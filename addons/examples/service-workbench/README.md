# Мастерская SDK 1

Работающий учебный пример для Noctune 1.4.0: панель во вкладке «Интеграции»,
условная видимость настроек, каталог и создание/переименование/удаление плейлистов,
добавление/удаление вхождений и порядок треков с ревизиями и requestId.
Учебные данные хранятся в Worker до отключения. Реальные серверы не используются.

Во вкладке «Расширения» появится браузер учебной медиатеки. В «Внешний вид»
можно выбрать «Графит · SDK 1», а в горячих клавишах — назначить сочетание
действию «Проверить состояние SDK». Назначение сочетания выполняет пользователь.
Расширение не получает события клавиатуры. Учебный текст песни включается отдельно.

Аудиопотоков в примере нет: кнопка воспроизведения сообщает об этом. Профиль
авторизации использует заглушку api.example.com: не вводите настоящие токены.
Для реального сервиса замените callbacks на адаптер API, объявите точные маршруты
и права, реализуйте проверку серверной ревизии и устойчивую идемпотентность запросов.

```sh
node scripts/pack-addon.cjs addons/examples/service-workbench addons/packages/service-workbench-demo.noctaddon
```

Это локальный учебный пакет без официальной подписи. Справочник:
[SDK 1](../../../docs/extensions-api-v1.md).
