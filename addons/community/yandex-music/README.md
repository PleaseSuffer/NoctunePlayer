# Яндекс Музыка для Noctune

Пользовательская интеграция с неофициальным API Яндекс Музыки для SDK 1,
Noctune 1.5.0. Работоспособность зависит от сервиса, аккаунта и доступности API.
Это независимое дополнение сообщества, не официальный клиент Яндекса.

## Установка

Откройте **Настройки → Расширения → Магазин → Пользовательские**, выберите
Яндекс Музыку и подтвердите разрешения. Затем включите расширение и откройте
**Настройки → Интеграции → Яндекс Музыка → Подключить**.

В окне подключения есть ссылки «Получить токен в Яндексе» и «Инструкция по
получению токена». Они открываются в системном браузере. Скопируйте только
значение OAuth-токена, без префикса OAuth. При желании укажите `expires_in`
в секундах: плеер вычитает сутки и прекращает использовать токен заранее.
Ручной токен не продлевается автоматически.

Токен вводится в защищённую форму Noctune и хранится через safeStorage.
Заголовок Authorization передаётся только api.music.yandex.net. Расширение
получает статус подключения, обложки и CDN загружаются без токена. На Linux
необходим работающий Secret Service/KWallet. Обновляйте поверх существующей
установки, чтобы сохранить профиль и настройки.

## Возможности

- Сохраняемые MP3 получают теги названия, исполнителей, альбома, исполнителя
  альбома, жанра, года, номера трека и диска, если эти данные предоставлены
  сервисом. Запись и проверка тегов завершаются до появления готового файла.
  Требуется сборка Noctune с поддержкой `downloads.start({metadata})`;
  старые сборки сохраняют аудио без добавления этих тегов.

- Скачивания показывают отдельные уведомления с прогрессом, объёмом и скоростью.
  Если размер неизвестен, показывается неопределённый прогресс без выдуманного процента.
  Кнопка отменяет все активные загрузки расширения; после завершения можно открыть
  папку сохранения. Ошибки и отмена снимают закрепление уведомления.
- Проверка подключения, истории и последней ошибки использует историю уведомлений;
  успешные проверки больше не отображаются как ошибки. Диагностику можно скопировать.

- Поиск треков, альбомов и исполнителей, библиотека и сервисные плейлисты.
- Моя волна и волна по треку, лайки и дизлайки, обложки и тексты песен.
- Действия с сервисными плейлистами и отправка истории воспроизведения.
- Сохранение доступного полного MP3 в папку приложения, загрузок или папку,
  выбранную пользователем. Доступность полного файла зависит от сервиса.

Разрешения на сеть ограничены маршрутами manifest. Ввод ключа, операции с
сервисом и сохранение файлов выполняются брокером Noctune. Существующие файлы
не перезаписываются. После отключения расширения активные запросы отменяются.

## Сборка из исходников

Из корня репозитория:

```sh
node scripts/pack-addon.cjs addons/community/yandex-music addons/packages/yandex-music.noctaddon
```

Для подготовки пакетов магазина и превью используйте
`scripts/publish-marketplace.cjs` по [инструкции публикации](../../../docs/extensions-publishing.md).
Пакет сообщества не имеет подписи официального издателя Noctune. Совпадение
контрольной суммы проверяется по каталогу; отсутствие подписи видно в окне установки.
Не добавляйте личные токены, настройки или закрытые ключи в исходники и пакет.
