# Анимированные превью тем

Превью — необязательный короткий ролик в карточке NocStore. Он запускается
при наведении, фокусе с клавиатуры или касании изображения. Одновременно
воспроизводится один ролик; код темы в магазине не выполняется.

При отсутствии ролика, ошибке загрузки, отключённых анимациях или системном
уменьшении движения показывается статичный баннер. Переключатель
**«Анимированные превью»** находится в шапке магазина. Там же можно очистить
дисковый кэш, ограниченный 50 МБ; старые ролики вытесняются автоматически.

## Формат и размещение

Рабочий профиль: **WebM/VP9 без звука, 960×540, 4 секунды, 20 кадров/с, CRF 24**.
Пределы: 8 МиБ, 1280×720, длительность от 1 до 6 секунд.

Файлы размещаются отдельно от пакета темы:

```text
addons/previews/<id>/<version>/preview.webm
addons/previews/<id>/<version>/metadata.json
```

`metadata.json` содержит размеры и длительность:

```json
{"width":960,"height":540,"duration":4}
```

Подписанный индекс `addons/catalog/previews.json` связывает ролик с ID, версией
и каналом темы, хранит URL, размер и SHA-256. Плеер проверяет индекс и файл
перед воспроизведением. Видео не включается в `.noctheme` или основной каталог
магазина и не требуется для работы темы.

## Создание и публикация

Нужны зависимости проекта, Electron и отдельно установленный FFmpeg.
Запускайте команды из корня репозитория. Тема уже должна присутствовать
в `addons/catalog/marketplace.json`, а её пакет — в `addons/distribution/`.
В примере замените `my-theme` на ID темы, пути — на свои:

```sh
./node_modules/.bin/electron scripts/render-theme-preview.cjs my-theme /usr/bin/ffmpeg --audio /path/to/sample.mp3 --start 45 --draft
```

Без `--audio` используется синтетический спектр. С аудиофайлом анализируется
четырёхсекундный фрагмент: по умолчанию из середины, либо с позиции `--start`
в секундах. Исходная музыка не изменяется и в ролик не попадает.

Параметры генератора:

- `--draft` — сохранить результат в `.development/preview-candidates/` для проверки.
- `--width 640|960|1280` — выбрать ширину; по умолчанию 960, пропорции 16:9.
- `--compare` — дополнительно сохранить MP4 и GIF для сравнения в `.development/`.

После проверки повторите рендер без `--draft`: генератор создаст `preview.webm`
и `metadata.json` в каталоге публикации. Уже существующий ролик не перезаписывается.
Для изменения опубликованного превью нужна новая версия темы.

Обновите индекс существующим ключом Noctune, хранящимся вне репозитория:

```sh
node scripts/publish-previews.cjs /secure/path/publisher.pem
```

Публикуйте ролик, метаданные и подписанный индекс вместе. Порядок публикации
самой темы описан в [инструкции по публикации](extensions-publishing.md).
В Windows вместо `./node_modules/.bin/electron` используйте
`.\node_modules\electron\dist\electron.exe`.

## Проверки

```sh
node tests/main/animated-previews.cjs
./node_modules/.bin/electron tests/native-animated-previews-probe.cjs
```

Проверяются целостность и кэширование файлов, воспроизведение в магазине,
возврат к статичному баннеру и режим уменьшения движения. Нативная проверка
использует изолированный профиль и локальные ролики.
