# Поиск по настройкам

Лупа рядом с кнопкой закрытия настроек раскрывает строку поиска. Когда настройки
открыты, поиск также вызывается сочетанием `Ctrl+F` (`Cmd+F` на macOS).

Поиск учитывает подписи, описания, названия вкладок и вложенных групп. Результаты
подсвечиваются, неподходящие вкладки затемняются, а ярлыки справа перестраиваются
по оставшимся разделам. При необходимости раскрываются вложенные параметры.

## Синонимы и дополнительные поисковые слова

Русские и английские подписи встроенных настроек индексируются одновременно,
независимо от выбранного языка интерфейса. Для других языков учитываются текущие
переведённые подписи; дополнительные русские и английские фразы тоже доступны.
Словарь разговорных формулировок помогает найти параметр без знания его названия.

| Настройка | Русские примеры | English examples |
| --- | --- | --- |
| Нормализация | `одинаковая громкость`, `выровнять громкость`, `тихие треки` | `normalization`, `volume leveling`, `equal loudness`, `quiet tracks` |
| ReplayGain | `теги громкости`, `нормализация` | `replaygain`, `loudness tags`, `volume metadata` |
| Кроссфейд | `плавная смена песен`, `переход между треками`, `фейд` | `smooth transition between songs`, `crossfade`, `fade in out` |
| Мини-плеер | `маленький плеер`, `плавающее окно`, `поверх окон` | `mini player`, `compact`, `floating window`, `always on top` |
| Прозрачность | `прозрачность`, `прозрачный` | `opacity`, `transparency`, `transparent` |
| Кэш обложек | `кэш обложки`, `кеш` | `artwork cache`, `clear cached images`, `album covers` |
| Проверка обновлений | `обновления проверка` | `automatic updates`, `check for new version`, `startup` |
| Запрет сна | `не выключать экран`, `не уходить в сон` | `keep screen awake`, `prevent sleep`, `stay awake` |
| Сворачивание в трей | `закрывать в трей`, `свернуть к часам` | `close to system tray`, `minimize`, `notification area` |
| Запоминание трека | `запомнить песню`, `последний трек` | `remember last song`, `track` |
| Восстановление воспроизведения | `сохранить позицию`, `продолжить слушать` | `resume playback`, `save restore position`, `continue listening` |
| Текст песни | `слова песни`, `лирика` | `lyrics`, `song words`, `text` |
| Визуализатор | `полоски`, `спектр`, `реакция на музыку` | `visualizer`, `visualiser`, `spectrum`, `audio reactive music bars` |
| Waveform | `форма волны`, `волна трека` | `waveform`, `audio wave`, `seek preview` |
| Частота эффектов | `фпс`, `плавность эффектов`, `ограничить кадры` | `fps`, `frame rate limit`, `effects performance` |
| Аппаратное ускорение | `видеокарта`, `ускорение графики` | `gpu`, `graphics`, `hardware acceleration` |
| Тема | `светлая`, `темная`, `ночной режим` | `theme`, `light`, `dark`, `night mode` |
| Язык | `язык`, `перевод`, `русский`, `английский` | `language`, `locale`, `translation`, `russian`, `english` |

Регистр не важен, `ё` и `е` считаются одинаковыми. Поиск поддерживает части слов.
Несколько слов проверяются вместе с учётом контекста раздела и группы; порядок
слов не важен. Например, `плеер нормализация` находит соответствующий параметр
во вкладке «Плеер».

Словарь задан вручную. Исправление опечаток и полноценный учёт склонений пока
не реализованы. При совпадении по дополнительному слову подсвечивается подходящий
элемент, даже если этого слова нет в его видимой подписи. Содержимое полей ввода
в поисковый индекс не попадает.

## Исправление раскладки

Если исходный запрос ничего не нашёл во всех вкладках, поиск повторяется с
переключением клавиш между стандартными русской ЙЦУКЕН и английской QWERTY
раскладками. Например, `ntvf` → `тема`, `ghjphfxyjcnm` → `прозрачность`,
`еруьу` → `theme`, `днкшсы` → `lyrics`, `;ehyfk` → `журнал`.
Преобразование выполняется до разбиения на слова, поэтому учитываются клавиши
пунктуации, соответствующие русским буквам.

Исходный текст в строке остаётся неизменным. При успешном исправлении строка
статуса показывает использованный запрос на языке интерфейса; подсветка и
переходы работают по исправленному запросу. Любое прямое совпадение имеет
приоритет. Если исправление тоже не помогло, остаётся обычное пустое состояние.
Это исправление раскладки, а не транслитерация или исправление опечаток.

## Очистка и подсветка

Удаление текста клавиатурой или крестиком внутри строки очищает результаты,
но оставляет строку открытой для следующего запроса. Пустая строка сворачивается
при клике снаружи или уходе фокуса. Лупа и `Esc` позволяют закрыть поиск явно.

После очистки восстанавливаются скрытые элементы и временно раскрытые группы.
Сам поиск не меняет значения настроек.

Видимые результаты периодически мягко подсвечиваются: примерно раз в пять секунд,
не более двух одновременно. Анимации останавливаются за пределами области
прокрутки, в скрытом окне и после закрытия поиска. При включённом системном
уменьшении движения остаётся статическая подсветка.
