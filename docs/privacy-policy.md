# Политика конфиденциальности (Privacy Policy)

Дата последнего обновления: 24 июня 2026 г.

## 1. Общие положения

Настоящая Политика конфиденциальности описывает порядок обработки данных при использовании NoctunePlayer.

## 2. Какие данные могут храниться

### Локальные данные

Приложение может сохранять на устройстве пользователя:

* настройки приложения;
* параметры воспроизведения;
* плейлисты;
* сведения о музыкальной библиотеке;
* кэшированные данные;
* кэш обложек альбомов;
* токены авторизации подключённых сервисов.

Эти данные хранятся исключительно на устройстве пользователя, если иное не предусмотрено используемым сторонним сервисом.

### Подключение сторонних аккаунтов

При использовании сторонних сервисов (например, Last.fm) Приложение может хранить:

* токены авторизации;
* идентификаторы аккаунтов;
* настройки интеграций.

Эти данные используются исключительно для обеспечения работы соответствующих функций.

## 3. Какие данные не собираются

Разработчики NoctunePlayer не осуществляют централизованный сбор следующих данных:

* музыкальной библиотеки пользователя;
* аудиофайлов;
* содержимого устройства;
* персональных файлов;
* истории прослушивания.

NoctunePlayer не передаёт такую информацию разработчикам.

## 4. Использование сторонних сервисов

Для работы отдельных функций Приложение может обращаться к сторонним сервисам.

Например:

* Last.fm;
* сервисам текстов песен;
* сервисам получения метаданных;
* сервисам получения обложек;
* сервисам проверки обновлений.

При использовании таких функций сторонним сервисам могут передаваться данные, необходимые для выполнения запроса, включая:

* название композиции;
* имя исполнителя;
* название альбома;
* версия приложения.

Использование сторонних сервисов регулируется их собственными политиками конфиденциальности.

## 5. Локальное хранение данных

NoctunePlayer сохраняет настройки и кэш-файлы локально для обеспечения корректной работы и повышения производительности.

Пользователь может удалить такие данные самостоятельно, удалив файлы конфигурации и кэша приложения.

## 6. Безопасность

Разработчики принимают разумные меры для защиты локально хранимых данных.

Однако ни одно программное обеспечение не может гарантировать абсолютную безопасность.

Пользователь самостоятельно отвечает за безопасность своего устройства и данных.

## 7. Использование детьми

Приложение не предназначено специально для детей и не содержит механизмов проверки возраста пользователей.

## 8. Международная обработка данных

Некоторые сторонние сервисы могут располагаться за пределами страны проживания пользователя.

Используя соответствующие функции, пользователь соглашается с возможной обработкой данных в других юрисдикциях.

## 9. Изменения политики

Настоящая Политика конфиденциальности может периодически обновляться.

Актуальная версия всегда публикуется в официальном репозитории проекта или на официальном сайте.

## 10. Контактная информация

По вопросам, связанным с обработкой данных и настоящей Политикой конфиденциальности, обращайтесь через официальный репозиторий проекта.
