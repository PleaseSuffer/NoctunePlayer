# Структура проекта

```text
src/
  main/
    index.js                    Главный процесс Electron: окна, IPC, интеграции
    cache/
      cover-cache-location.js   Выбор папки кэша обложек
    integrations/
      lastfm/cover-service.js   Поиск, скачивание и кэширование обложек
      lrclib/lyrics-service.js  Получение текста песни и разбор LRC
  preload/
    index.js                    Мост window.noctune, файлы и метаданные аудио
  renderer/
    index.html                  Интерфейс приложения и порядок загрузки скриптов
    core/                       Начальная загрузка, DOM, общее состояние, хранилище
    playback/                   Аудиодвижок, управление воспроизведением, эквалайзер
    library/                    Плейлисты и импорт/экспорт музыкальной библиотеки
    integrations/              Интерфейс текста песни и поиск радиостанций
    effects/                   Фон, визуализатор, waveform, конфетти и фейерверки
    ui/                        Настройки, уведомления и горячие клавиши
    updates/                   Интерфейс обновления приложения
    styles/                    Стили интерфейса
  web/
    redirect.html              Отдельная веб-страница для ссылок noctune://
resources/                     Иконки и ресурсы установщика
docs/                          Документация
tests/
  main/                        Сервисы, кэш и поиск обложек
  renderer/                    Воспроизведение и интерфейс текста песни
  structure/                   Проверка путей модулей и ресурсов
  run.cjs                      Запуск всех проверок
```

`npm start` запускает `src/main/index.js`. Главное окно загружает `src/renderer/index.html`,
а API Electron и файловой системы доступны интерфейсу через `src/preload/index.js`.
`src/web/redirect.html` публикуется отдельно от интерфейса приложения.

Скрипты renderer используют общие функции и состояние. При добавлении или переносе
скрипта нужно сохранять порядок подключения в `src/renderer/index.html`: сначала
хранилище и общее состояние, затем функции приложения, после них начальная загрузка
и настройки. Перенос файлов не меняет модель их выполнения.

Проверки запускаются командой `npm test`. Упаковка `npm run dist` включает всё дерево
`src/**/*`, поэтому новые папки попадут в сборку автоматически.
