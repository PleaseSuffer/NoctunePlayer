# Интерактивные фоны Noctune — API v1

Плеер также поддерживает [Scene API v2](SCENE-API-V2.md): переносимые поверхности, PNG-маски, общий источник спектра и типизированные параметры. Эта страница сохраняет контракт v1; существующие темы не требуют миграции.

Тема — директория с `manifest.json`, `scene.js` и PNG-слоями. Для передачи и импорта она упаковывается в один файл `.noctheme`: JSON-контейнер со встроенными изображениями и скриптом. Пакет не зависит от исходных путей и не требует распаковки архива.

В плеере: **Настройки → Внешний вид → Темы → плитка +**. Плитка импорта находится в галерее добавленных тем. Встроены три сцены: «Ночной холм», «Дождь у окна» и «Одержимость». В галерее обычных фонов восемь вариантов. Превью заполняют ширину блока, сохраняя минимальный размер, и переносятся на следующую строку. Внешний вид содержит девять разделов с ярлыками справа для перехода прокруткой. Раздел «Темы» идёт сразу после «Фон». Их переключатели взаимоисключающие; последний выбор картинки и темы сохраняется независимо. Недавние фоны доступны и при активной теме: клик по картинке переключает плеер обратно в обычный режим. При активной сцене скрыты обычные визуальные эффекты, визуализатор, конфетти и параметры обычных звёзд: сценой управляет её собственный скрипт.

## Исходники и сборка

```text
themes/user/my-theme/
  manifest.json
  scene.js
  assets/
    preview.png
    sky.png
    land.png
    character.png
```

```json
{
  "id": "my-night-scene",
  "name": "Ночная сцена",
  "description": "Столбики за горами и падающие звёзды",
  "author": "Your name",
  "version": "1.0.0",
  "width": 1920,
  "height": 1080,
  "preview": "preview",
  "palette": {
    "accent": "#b699ef",
    "background": "#0b0d1b",
    "gradient": ["#73bdd5", "#aa87e0", "#edbfa0"]
  },
  "capabilities": { "visualizer": "bars", "motion": true },
  "parameters": { "frequencyMix": 0.6, "glowIntensity": 1 },
  "assets": {
    "preview": "assets/preview.png",
    "sky": "assets/sky.png",
    "land": "assets/land.png",
    "character": "assets/character.png"
  },
  "script": "scene.js"
}
```

```powershell
node scripts/pack-scene-theme.cjs themes/builtin/02-night-hill themes/packages/02-night-hill.noctheme
node scripts/pack-scene-theme.cjs themes/builtin/03-rain-window themes/packages/03-rain-window.noctheme
node scripts/pack-scene-theme.cjs themes/builtin/05-obsessed-over-camera themes/packages/05-obsessed-over-camera.noctheme
```

Все пути исходников относительны директории темы. Выход за её пределы, включая символьные ссылки, отклоняется. `width` и `height` задают логическую систему координат; слои должны совпадать по композиции и размеру. «Ночной холм» и «Дождь у окна» используют слои 1920×1080; старые темы с другим холстом продолжают масштабироваться в режиме cover. Превью рекомендуется 320×180 PNG. В списке недавних картинок сохраняются десять фонов; увеличение списка с шести до десяти не уменьшает плитки.

## Жизненный цикл

```js
NoctuneScene.define({
  async init(api) { /* необязательно; изображения уже декодированы */ },
  render(api, frame) {
    api.layer('sky');
    api.shootingStars();
    api.bars({ x: 60, y: 650, width: 1800, height: 200 });
    api.layer('land'); // маска земли закрывает нижнюю часть визуализатора
    api.character('character', { anchor: 1000, hairY: [220, 480] });
  }
});
```

`render` вызывается хостом, свой `requestAnimationFrame` не нужен. Все слои и эффекты используют один Canvas и общую систему координат. При смене темы iframe удаляется целиком вместе с обработчиками, таймерами и ресурсами. Предыдущая сцена остаётся активной до первого успешно нарисованного кадра новой; ошибка замены сохраняет прежнюю сцену.

`frame` содержит `width`, `height` (CSS-размер окна), `dpr` (ограничивается движком до 1.5), `dt` (секунды, максимум .08), `time` (время анимации окружения), `motion`, `audio`. `audio` содержит `spectrum` (Uint8Array, FFT-амплитуды 0…255), `sampleRate`, `playing`, `enabled`, `intensity`. Длина спектра сохраняется для правильного соответствия частот бинóм. При паузе хост передаёт тишину, реакция на звук плавно затухает. Окружение продолжает жить без музыки. Свёрнутое/скрытое окно останавливает отправку кадров; после возврата время не перескакивает.

Переключатель анимаций и системный `prefers-reduced-motion` отключают дыхание, волосы, моргание, движение дождя и звёзд. Визуализатор включается отдельно, его отключение также гасит свечение глаз и контура. Настройка FPS общая с остальными эффектами плеера. Хост допускает только один неподтверждённый кадр на сцену, чтобы не накапливать сообщения при медленном рендеринге.

## Методы SDK

| Метод / свойство | Назначение |
| --- | --- |
| `ctx`, `canvas`, `width`, `height`, `images`, `manifest`, `palette` | Canvas 2D, логические размеры, декодированные слои и описание |
| `time`, `dt`, `motion`, `audio` | Текущее состояние кадра |
| `layer(id, opacity = 1)` | Рисует слой на весь логический холст |
| `clip(polygons, draw)` | Ограничивает рисование набором полигонов `[[[x,y],…],…]` |
| `plane({origin,xAxis,yAxis,relative=false,width,height}, draw)` | Независимые наклоны двух осей, масштаб, сдвиг и отражение на плоскости; draw использует локальные координаты |
| `gradient(x0,y0,x1,y1)` | CanvasGradient из трёх цветов темы |
| `spectrum(count=96, minHz=35, maxHz=18000, key='main', spacing='hybrid')` | RMS-полосы 0…1 с дробными границами отсчётов и сглаживанием; spacing: hybrid, linear, log; кеш на кадр |
| `bars({x,y,width,height,count=96,opacity=.8,minHz,maxHz,spacing})` | Градиентные столбики от нижней базовой линии `y` |
| `line({x,y,width,height,opacity=.3,reflection=false,count=128,fill=.3,adaptiveFill=false,hideWhenSilent=false,minHz,maxHz,spacing})` | Линия со свечением и градиентной заливкой; adaptiveFill подстраивает градиент под высоту текущего спектра, hideWhenSilent скрывает линию при тишине; fill=0 отключает заливку |
| `character(id, options)` | Дыхание с фиксированной нижней опорой и движение волос; параметры ниже |
| `light(x,y,radius,opacity,color=palette.accent)` | Мягкий свет с режимом screen |
| `flicker([[x,y,radius,color,strength],…])` | Независимое мерцание источников; цвет и сила необязательны |
| `rain()` | Прозрачные капли преломляют слой outside; случайные участки траектории с боковым дрейфом, коротким замедлением перед поворотом и плавным разгоном. Потёки хранят реальные координаты пути, имеют переменную толщину, ответвления и мелкие капли. Длина хвостов различается (24–304 пикселя сцены), пересечения образуют более крупные водяные линзы с плавным высыханием. История ограничена 64 точками на каплю и 96 утолщениями, поиск пересечений использует пространственную сетку. Ограничивайте окном через clip |
| `shootingStars({minInterval=6,maxInterval=14})` | Криволинейные следы с плавным затуханием; интервал появления в секундах |
| `energy`, `pulse` | Энергия выбранной смеси частот и краткий импульс на росте сигнала |

`character` принимает `anchor` (Y опоры), `hairY: [top,bottom]`, `blink` (ID PNG с закрытыми глазами), `eyes: [[x,y,w,h],…]` (маски только глаз), `contour: true`, `eyeGlow: [[x,y,radius],…]`. Для одержимого взгляда `blink` отсутствует. Контур использует альфа-силуэт, мягкое свечение и до четырёх расширяющихся импульсов одновременно. Это лёгкая процедурная анимация плоского арта, не Live2D-модель с костями.

Окно рисует внешний вид, спектр и дождь внутри полигонов стекла, затем интерьер. Прозрачность линии 70% означает `opacity: .30`. Встроенная тема не отражает визуализатор на подоконнике. Возможность `line({reflection:true})` остаётся доступной авторам других тем.

## Палитра и настройки

`bars` и `line` поддерживают `smoothing` (0…1, по умолчанию 0 для совместимости). Это смешивание исходного спектра со взвешенной выборкой пяти соседних полос, без изменения FFT или объединения частот в группы. «Ночной холм» использует 0.8, «Дождь у окна» — 0.65. Временное сглаживание атаки и затухания остаётся независимым.

Визуализатор темы использует отдельный переключатель `setting_scene_visualizer_enabled` (по умолчанию включён). Он не меняет обычный `setting_show_viz` и не зависит от него. Отклик на звук и доля частот вложены в переключатель сцены и скрыты при выключении или отсутствии поддержки. Мерцание окружения и дождь продолжаются независимо от аудио.

`manifest.parameters` задаёт значения по умолчанию: `frequencyMix` (0…1 — доля средних и высоких частот, остальное бас 35…280 Гц), `glowIntensity` (0…3). Блок необязателен в API v1: старые пакеты получают 0.6 и 1. Параметры сохраняются упаковщиком и импортом `.noctheme`; ползунки раздела «Темы» сохраняют значения отдельно для каждой темы. Экспорт/импорт кода настроек плеера передаёт их через `sceneParameters`. Хост отправляет долю в `frame.audio.frequencyMix`, свечение — в `frame.lighting.intensity`. SDK применяет его к light/flicker, глазам, контуру и свечению визуализатора. Значение 0 отключает добавленный свет, сохраняя оригинальный арт.

Сцены используют отдельный AnalyserNode с FFT 8192 (4096 отсчётов), без изменения анализатора обычных эффектов. Hybrid-разбиение распределяет полосы по диапазону 35…18000 Гц без повторного чтения одного басового отсчёта группами; дробные границы сглаживают переходы. Отклик персонажа смешивает RMS и пики басовых и средних/высоких полос, поэтому свечение доступно и для музыки без выраженного баса.

`plane` задаёт аффинную плоскость двумя независимыми базисными векторами. `origin` — начало, `xAxis`/`yAxis` — направления осей. В режиме `relative:true` координаты задаются долями исходного изображения; `width`/`height` — логические размеры локальной плоскости (по умолчанию размеры сцены), поэтому локальные размеры и толщина линий остаются в пикселях арта. Отрицательная ось Y даёт отражение. Это аффинная проекция без перспективного схождения точек; её можно вложить в clip и другую plane.

```js
api.clip(windowPolygons, () => {
  api.plane({origin:[0,.888], xAxis:[1,-.248], yAxis:[.07,.84], relative:true}, () => {
    api.line({x:0, y:0, width:1400, height:65, count:128, opacity:.30, fill:.95, adaptiveFill:true, hideWhenSilent:true});
  });
});
```

`palette.accent` временно становится акцентом интерфейса и адаптивного waveform; `gradient` передаётся общим потребителям градиента плеера. Скрипт использует палитру самой сцены независимо от переключателя «Цвета плеера из темы». Ручные настройки цветов не перезаписываются. При выходе из сцены восстанавливаются сохранённые акцент и градиент. Автоматическое извлечение палитры из обычной картинки не запускается поверх сцены.

`capabilities.visualizer`: `bars`, `line`, `character` или `none`. `motion` разрешает переключатель анимаций. В первой версии тип и геометрия визуализатора определяются сценой; пользователь управляет включением и интенсивностью отклика. Обычные настройки эффектов сохраняются и возвращаются при выборе картинки/видео.

## Хранение и границы выполнения

Все исходники находятся в корневой папке `themes/`: `builtin/` содержит три встроенные сцены, `user/` — локальные пользовательские темы, `backgrounds/` — обычные фоны, `packages/` — справочные экспорты. Для разработки новой темы создайте директорию `themes/user/my-theme/` с манифестом, скриптом и слоями либо положите готовый пакет `my-theme.noctheme` в `themes/user/`. Имена директорий и пакетов: строчные латинские буквы, цифры и дефисы. Коллекция обновляется при запуске, импорте или удалении темы. Крестик удаляет импортированные копии и скрывает папки исходников без удаления файлов. Повторная установка возвращает тему.

В режиме разработки импортированные файлы сохраняются в `themes/user/`. В установленном приложении ресурсы внутри `app.asar` доступны только для чтения, поэтому новые импорты сохраняются в `app.getPath('userData')/themes/user`. Поставляемые пользовательские темы и импортированные копии с одинаковым `manifest.id` объединяются в одну карточку: выбирается новейшая версия, при равенстве — импорт. Удаление записывается в `.hidden-themes.json` каталога импорта и сохраняется после перезапуска. Сборка включает `themes/builtin`, `themes/backgrounds` и локальные `themes/user`; папка экспортов повторно не упаковывается. Кастомные темы, изображения и промпты из `themes/user` исключены из Git. Справочные примеры API публикуются отдельно в `themes/examples`.

Имя импортированного файла — хеш содержимого; повторный импорт одинакового пакета не создаёт дубликат. Старые импорты из `app.getPath('userData')/scene-themes` автоматически копируются в новый каталог с сохранением ID; исходные файлы остаются на месте. Удаление встроенной темы запрещено. Формат API версионируется; неизвестная версия отклоняется.

Скрипт запускается в iframe с `sandbox="allow-scripts"`, без same-origin, Node, preload и доступа к DOM плеера. CSP запрещает сеть, внешние изображения, фреймы, формы и объекты. Пакет допускает только встроенные PNG: до 24 слоёв, размер до 4096×4096 каждый, общий предел 48 млн пикселей и 64 МБ контейнера; скрипт — до 128 КиБ. Изображения всё равно декодируются браузером перед запуском. Это изоляция возможностей, а не гарантия против скрипта, намеренно расходующего CPU; импортируйте темы из известных источников.

## Проверки

```powershell
npm test
.\node_modules\.bin\electron.cmd tests/native-scene-themes-probe.cjs
.\node_modules\.bin\electron.cmd tests/native-scene-themes-probe.cjs --full-app
```

Первая команда проверяет контейнер, защиту путей, ограничения, дедупликацию, пользовательские исходники, миграцию старых импортов и динамику спектра. Вторая рисует все три сцены в Electron, проверяет отсутствие Node/preload, запрет доступа к родителю, управление вкладками, наследование/возврат акцента и откат ошибочной замены. Третья запускает настоящий main/preload/renderer с отдельным тестовым профилем и проверяет IPC, выбор встроенной темы и выключение фона. Тестовые профили и предпросмотры сохраняются в игнорируемом `tests/.artifacts/scene-themes/`.
