# API тем Noctune · v2

API v2 расширяет SDK тем переносимыми поверхностями, альфа-масками, общим спектром и проверяемыми пользовательскими настройками. Пакеты API v1 продолжают загружаться с прежними значениями по умолчанию. Версия приложения не меняется автоматически вместе с версией API.

## Быстрый старт

Готовый минимальный пример и инструкция находятся в [themes/examples/api-v2](../themes/examples/api-v2/README.md). Скопируйте его в локальную папку `themes/user/my-theme`, измените `manifest.id`, название и PNG-слои, затем откройте тему в плеере. Для распространения упакуйте её:

```powershell
node scripts/pack-scene-theme.cjs themes/user/my-theme themes/user/my-theme.noctheme
```

Откройте `.noctheme` через окно установки. Для следующего обновления сохраните `manifest.id` и увеличьте `manifest.version`. Установка новой версии активной темы автоматически перезапускает сцену: старая остаётся видимой до первого успешного кадра новой. Если запуск обновления завершается ошибкой, работающая сцена сохраняется; установленный файл автоматически не откатывается.

Галерея объединяет папку исходников и импортированные копии с одинаковым ID; отображается новейшая версия, при равенстве предпочтителен импорт. Крестик удаляет добавленную тему из галереи: импортированные файлы удаляются, исходники сохраняются и скрываются до повторной установки. Встроенные темы защищены от удаления. Кастомные темы в `themes/user` не публикуются в Git; пример SDK находится отдельно в `themes/examples`.

## Выбор версии и миграция

Укажите `"apiVersion": 2` в `manifest.json`. Упаковщик перенесёт версию в контейнер `.noctheme`; несовпадение двух версий отклоняется. Отсутствие поля в исходном манифесте означает v1. Контейнер всегда содержит версию. Старый плеер, поддерживающий только v1, отклонит v2; новый поддерживает обе версии.

При миграции замените `document.createElement('canvas')` на `api.createSurface(width, height)` и обращайтесь к полученной поверхности через `getContext('2d')`. `runtimeRequirements: { "dom": false }` означает попытку запуска Worker с откатом в iframe при недоступности платформы или ошибке запуска. `{ "dom": true }` сразу выбирает iframe. Worker всё равно работает внутри изолированного iframe: тема не получает доступ к DOM плеера. CSP, запрет сети, лимиты PNG/скрипта и проверка путей не ослаблены.

Старые методы `layer`, `clip`, `plane`, `spectrum`, `bars`, `line`, `character`, `light`, `flicker`, `rain` и `shootingStars` доступны в v2. Для v1 изменено только восстановление контекста в `clip` при исключении callback. Значения и остановка эффектов v1 сохранены. В v2 время эффектов локальное, поза персонажа и звёзды по умолчанию замораживаются; это сознательное изменение поведения.

Типы: [`sdk.d.ts`](../themes/sdk.d.ts). В обычном JS используйте `/// <reference path=".../themes/sdk.d.ts" />`. Декларации описывают публичный контракт v2.

## Контракт кадра

`render(api, frame)` вызывается хостом. Собственный цикл `requestAnimationFrame` не требуется. Первый кадр рисуется даже в скрытом кандидате; переключение происходит только после успешной отрисовки. Ошибка нового кандидата оставляет старую сцену активной.

| Поле | Единицы и поведение |
| --- | --- |
| `width`, `height` | Размер viewport в CSS px |
| `dpr` | DPR устройства; SDK применяет ограничение профиля |
| `dt` | Секунды, 0…0.08; в первом кадре 0 |
| `time` | Секунды общего времени анимации хоста; растёт при разрешённом движении |
| `motion` | Учитывает настройку анимаций, системный reduced motion и capability темы |
| `reducedMotion` | Системный запрос уменьшения движения |
| `parameters` | `frequencyMix`, `glowIntensity` и значения схемы темы |
| `lighting.intensity` | 0…3, множитель дополнительного свечения |
| `safeArea` | Прямоугольник мини-плеера в CSS px или null |
| `audio.spectrum` | Исходные FFT-амплитуды 0…255, Uint8Array; в первом кадре может быть пустым обычным массивом |
| `audio.sampleRate` | Частота дискретизации в Hz; Nyquist = sampleRate / 2 |
| `audio.playing` | Состояние воспроизведения; пауза передаёт пустой спектр |
| `audio.enabled` | Включён ли визуализатор темы |
| `audio.intensity` | Общий множитель реакции, хост ограничивает 0.1…3 |
| `audio.frequencyMix` | 0…1, баланс низких и средних/высоких частот для energy/pulse; диапазоны отдельных спектров не меняет |

`api.time` в v2 — локальное время движения этой сцены, начинается с 0 и растёт на `dt` только при `motion=true`. Используйте его для поз и частиц: переход в reduced motion сохраняет фазу. Для собственного эффекта `frame.time` тоже доступно, но согласованную политику остановки должен обеспечить автор.

`energy` имеет диапазон 0…1. `pulse` сохраняет исходный диапазон 0…2.6: это оценка фронта, которая может превышать 1. `normalizedPulse` — отдельное поле v2 с ограничением 0…1. При паузе и выключенном визуализаторе спектр, energy и pulse продолжают плавно затухать.

| Состояние | Результат |
| --- | --- |
| playing=true, visualizer=true | Спектр и аудиосвечение реагируют на звук |
| playing=false либо visualizer=false | Аудиореакция затухает; разрешённое движение окружения продолжается |
| motion=false | Дождь, звёзды и поза персонажа заморожены; аудиореакция независима |
| lighting=0 | Дополнительный blur/свечение SDK исчезает; сам силуэт/след остаётся виден |
| character/stars `stop: 'hide'` | Эффект скрывается при motion=false; значение по умолчанию — freeze |
| Скрытое/свёрнутое окно | Отправка кадров останавливается, накопленного скачка времени нет |

## Поверхности, ресурсы и события

`createSurface(width=api.width, height=api.height)` возвращает OffscreenCanvas, если доступен, иначе HTMLCanvasElement. Размеры — целые 1…4096. Поверхности создаются прозрачными. Освобождайте временные через `releaseSurface(surface)`; `dispose()` освобождает оставшиеся SDK-поверхности и закрывает ImageBitmap. Лимиты проверяются при создании; самостоятельное изменение размеров native Canvas и прямое использование платформенных API остаётся ответственностью автора.

`replaceImage(id, image)` заменяет существующий слой, закрывает предыдущий bitmap и инвалидирует кеши масок, персонажей и контуров. `setPalette(palette)` проверяет три цвета градиента и инвалидирует кеши. Прямое изменение `images`/`palette` допустимо для совместимости, но после него нужно вызвать `invalidate()`. `reset()` сбрасывает время, аудиореакцию, частицы и кеши, сохраняя текущие изображения, параметры и поверхности автора. `dispose()` идемпотентен; после него создание поверхностей и begin запрещены.

Через `api.on(event, callback)` доступны `resize`, `parameters`, `audio`, `resources`, `reset`, `dispose`; возвращается функция отписки. `audio` уведомляет об изменении playing/enabled/sampleRate/длины FFT, а не о каждом изменении амплитуд. `resize` передаёт CSS-размеры и DPR. Необязательные callbacks в `NoctuneScene.define`: `resize(api, viewport)`, `parameters(api, values)`, `audio(api, state)`, `reset(api)`, `dispose(api)`. Они синхронные; асинхронным может быть только `init`. При удалении iframe хост делает попытку вызвать dispose; ручное освобождение во время жизни сцены остаётся основным способом управления ресурсами.

## Маски и композиция

```js
api.compose({
  background: () => api.layer('sky'),
  effects: () => api.clipMask('towers', () => {
    api.bars({ x: 120, y: 700, width: 1600, height: 180 });
  }, { invert: true }),
  foreground: () => api.layer('towers')
});
```

Группы всегда рисуются в порядке background → effects → foreground; каждая защищена save/restore. Это немедленные callbacks, не сохраняемый граф сцены. Прямой Canvas остаётся доступным.

`clipMask(asset, draw, { invert=false, feather=0 })` рисует callback в отдельную прозрачную поверхность и применяет **альфу** PNG; цвет маски не важен. Прозрачное отверстие скрывает эффект; `invert` меняет правило. Полупрозрачность сохраняется, feather задаёт blur 0…32 логических px. Альфа-маска и изображение растягиваются до полного логического холста. Маски кешируются по asset/feather и освобождаются при инвалидизации; временная поверхность освобождается и при ошибке callback. Во время callback `api.ctx` указывает на промежуточный контекст: берите его внутри callback, не используйте сохранённую снаружи ссылку.

`sceneToScreen(x,y)` и `screenToScene(x,y)` переводят логические координаты и CSS px с учётом cover. `visibleRect` показывает видимую часть логического холста, `anchor(horizontal=.5, vertical=.5, inset=0)` возвращает точку внутри неё. `api.safeArea` переводит область мини-плеера в координаты сцены; null означает отсутствие области. Эти преобразования описывают основной холст, не локальную систему `plane`.

Чтобы изменить левую границу спектра, изменяйте x/width, сохраняя count/minHz/maxHz. Все полосы перераспределятся внутри новых границ. Обрезание маской меняет видимость, но не распределение частот.

## Общий источник спектра

```js
const source = api.bandsSource({
  count: 96, minHz: 35, maxHz: 18000, spacing: 'hybrid',
  attack: 18, release: 7, smoothing: .35
});
const draw = () => api.bars({ x: 60, y: 650, width: 1800, height: 200, source });
draw();
api.reflection({ baseline: 700, height: 250, mask: 'water' }, draw);
api.line({ x: 60, y: 650, width: 1800, height: 200, source, hideWhenSilent: true });
```

Источник — переиспользуемый Float32Array 0…1; получить его нужно после begin в render каждого кадра. Одинаковые параметры возвращают одну выборку в кадре, сглаживание не применяется повторно в bars/line. `source` также принимает функцию или обычный массив. Полученный массив не изменяйте и не используйте как исторический снимок; для снимка копируйте его.

count: целое 2…512; minHz > 0; maxHz > minHz, до 96000; spacing: linear/log/hybrid; attack/release: положительные экспоненциальные скорости в 1/сек; smoothing: 0…1. Диапазон выше Nyquist даёт пустые полосы. Геометрия FFT кешируется по count/range/spacing/sampleRate/длине спектра. Массив пространственного сглаживания переиспользуется. `spectrum(...)` со старой сигнатурой доступен; в v2 его аргументы проверяются и динамические ключи ограничены.

## Параметры темы

Элементы схемы используют оформление настроек приложения: slider располагается под подписью на всю ширину строки, значение выровнено справа; toggle отображается штатным переключателем, select — оформленным списком. Значения slider привязываются к сетке шага от min и округляются с точностью min/max/step перед сохранением и отправкой в frame. Поэтому десятичный шаг 0.1 не выводит и не сохраняет хвосты вроде 1.2000000000000002. Если max не принадлежит сетке, верхним значением становится последний допустимый шаг ниже max.

```json
"parameterSchema": {
  "waves": { "type": "slider", "label": { "ru": "Волны", "en": "Waves" }, "default": 1, "min": 0, "max": 2, "step": 0.1 },
  "crown": { "type": "toggle", "label": "Корона", "default": true },
  "style": { "type": "select", "label": "Спектр", "default": "line", "options": [{ "value": "line", "label": "Линия" }, { "value": "bars", "label": "Столбики" }] }
}
```

До 24 параметров, ключи `/^[a-z][a-zA-Z0-9]{0,47}$/`; frequencyMix/glowIntensity и prototype/constructor зарезервированы. Неизвестные поля схемы, HTML в подписях, обработчики и выражения отклоняются. Подпись — строка либо до восьми локализаций; текущий интерфейс выбирает ru, затем en, затем первую. Select содержит до 16 уникальных строковых вариантов. Настройки появляются в разделе темы и передаются как `frame.parameters`/`api.parameters`.

Slider проверяется, округляется к step от min и ограничивается min/max; toggle принимает boolean; select принимает только объявленный вариант. Невалидное сохранённое значение заменяется default. Сохранение v2 использует `manifest.id`, а не имя файла или хеш импорта: обновление с тем же ID/ключом сохраняет настройки. Удалённые ключи не попадают в frame, новые получают default. Старые preferences по ID галереи читаются как резервный источник и при следующей записи переходят на стабильный ID.

`capabilities.visualizers` объявляет несколько используемых типов, включая radial. Основной `visualizer` обязателен и должен входить в этот список; none должен быть единственным типом.

## Готовые эффекты и качество

`radialSpectrum({ x, y, radius, height, source, opacity, color, glow, startAngle, endAngle })` рисует радиальные столбики Canvas 2D. При тишине нулевые столбики пропускаются. glow умножается на lighting.

`reflection({ baseline, height, opacity=.35, distortion=2, strips=48, mask, invert=false }, draw)` отражает результат callback относительно baseline и затухает вниз. strips: 1…128. Искажение использует замораживаемое время движения. Callback работает с временным `api.ctx`; маска ограничивает готовое отражение. Высота не превышает высоту сцены.

`waterRipple({ x, y, radius=80, strength=1, opacity=.3, color, rings=3, speed=1 })` рисует затухающие эллиптические кольца. Свет управляет дополнительным blur, motion — фазой колец. Для воды вне колец используйте собственную поверхность/Canvas.

`character` расширен `breathAmplitude=.0035`, `hairStrength=1.5`, `blinkInterval=5.9`, `contourColor=palette.accent`, `stop='freeze'`. hairY по-прежнему определяет диапазон строк, это не костная модель. `shootingStars` расширен color, opacity, glow и stop. Цвет контура включён в инвалидизацию кеша персонажа.

| quality | Max DPR | Капли/звёзды | SDK-поверхности | Сумма пикселей поверхностей | Записи каждого кеша |
| --- | --- | --- | --- | --- | --- |
| low | 1 | 40 | 8 | 16 Mi px | 16 |
| balanced, по умолчанию | 1.5 | 80 | 12 | 32 Mi px | 32 |
| high | 2 | 120 | 16 | 48 Mi px | 64 |

Профиль фиксирован в манифесте; автоматического переключения пока нет. Буферы персонажа, масок и отражений учитываются в лимите поверхностей. Для очень больших сцен используйте меньшие поверхности и освобождайте временные. Это бюджет SDK, не ограничение всей памяти JavaScript/GPU.

## Диагностика и проверки

В консоли плеера `sceneThemes.diagnostics(true)` включает ограниченное окно 240 образцов. `sceneThemes.performance` возвращает runtime, fallbackReason, decodeMs, renderMs, frameLimit, frames, а в режиме диагностики — p50/p95 CPU render, roundTripMs, effectiveFps и skipped. roundTripMs — путь сообщения туда/обратно с отрисовкой; это не отдельная задержка транспорта. skipped считает пропуски при занятом runtime, а не все ограничения FPS/статичные кадры. renderMs не измеряет GPU или физический вывод на экран. `diagnostics(false)` выключает сбор и очищает образцы.

```powershell
npm test
node scripts/generate-v2-example-assets.cjs
node scripts/pack-scene-theme.cjs themes/examples/api-v2 themes/packages/api-v2-demo.noctheme
```

Готовый пример: `themes/packages/api-v2-demo.noctheme`. Его исходники находятся в `themes/examples/api-v2`; импортируйте пакет через галерею. Он использует одни bands для спектра и отражения, PNG-маску башен, независимую маску воды и все три типа настроек. Node-тесты проверяют валидацию, затухание, частоты дискретизации/FFT, координаты, лимиты и dispose.

## Ограничения контракта

В эту версию контракта не входят отдельный редактор композиции с проигрыванием музыки и курсором, projectivePlane, обработчики пользовательских/клавиатурных событий, crossfade, откат файлов пакета после неудачного обновления, независимые маски прядей, пресеты обмена и автоматический профиль качества. Проверка импорта с превью уже существует; безопасное переключение после первого кадра относится к активной сцене и не является дисковым откатом установленного пакета.

Оптимизации границ персонажа, статичной позы, отражающих полос и количества Path2D требуют отдельных сравнительных измерений. Добавленные кеши имеют лимиты и функциональные проверки; численный прирост FPS/p95 не заявляется. Перед выпуском нужны замеры на целевых устройствах и визуальная проверка авторских тем «Эхо заката» и «Память воды» с реальной музыкой.
