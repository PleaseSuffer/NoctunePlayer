Кнопка «Слушать» у радио
Друг сможет запустить ту же радиостанцию у себя
Ручная настройка
Свой Application ID и URL для кнопки «Слушать»
Application ID (Client ID)
discord.com/developers/applications → New Application → Application ID на странице General Information.
Базовый URL для кнопки «Слушать» (необязательно)
Discord принимает в кнопках только http(s)-ссылки. Без этого URL кнопка просто откроет поток радио в браузере; со страницей-редиректом — запустит ту же станцию в копии плеера у друга.
